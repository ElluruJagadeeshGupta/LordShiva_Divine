# 🔱 Lord Shiva — A Python Terminal Tribute

A small Python project inspired by Lord Shiva. Run it in the terminal and enjoy a text-based tribute created with code.

## Run it

You’ll need Python installed. Open a terminal in this folder and enter:

```powershell
py .\Shiva.py
```

## Project file

- `Shiva.py` — runs the Lord Shiva terminal tribute.

## About

This project is a personal coding practice project, made to bring together programming and a subject of cultural and spiritual significance. It’s a simple starting point that can grow with new ideas and features.
